# NIYOPLAN PROJECT

Project Vision: A modern, Jira-like agile project management platform with deep multi-tenant security and a premium UI/UX.

## Core Pillars
1. **Security**: Deep organizational isolation and precise RBAC.
2. **Experience**: Fast, reactive, and fluid Jira-like Kanban and Dashboards.
3. **Simplicity**: No-fluff interfaces and intuitive project coordination.

## Technical Foundation
- **Framework**: Next.js 15 (App Router, Server Actions)
- **State/Auth**: React 19, Context API, Supabase Auth
- **Data**: Supabase PostgreSQL (Row-level Security + custom API isolation)
- **UI**: Tailwind CSS v4, Lucide Icons, dnd-kit

## Current Focus
Resolution of stability bugs and improving UI/UX flow.
Specific annoyance: Annoying page refreshes/loaders on tab switch focus.
